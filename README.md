## Какво съдържа порталът?
Пълен, възпроизводим и автоматично верифициран граждански анализ на **абсолютно всички 571 длъжностни лица** (512 с пряка собственост/управление/роднински дял + 59 членове на съвети), извлечени директно от публичния API на държавната платформа **СИГМА 2.0** (`https://sigma.midt.bg`), разработена от Министерството на иновациите и дигиталната трансформация (МИДТ).

### Основни модули:
1. **Пълен регистър на всички 571 лица (`0 пропуснати`)** — мигновено търсене по име, фирма, ЕИК, община, министерство, роднина или възложител; филтри по кръгове; подреждане по стойност и риск индекс.
2. **Интерактивен граф на кръговете на свързаност** — визуална мрежа `Институция ↔ Длъжностно лице ↔ Роднина (ТР) ↔ Фирма (ЕИК)` за:
   - 🔥 Кръг „Самовъзлагане“ (договори **от собствената институция**)
   - 🏛️ Кръг „Народно събрание“ (депутати)
   - 🛡️ Кръг „Служби за сигурност и висша власт“ (ДАНС, ДАТО, Министерства, НЗОК, Агенция „Митници“, АГКК)
   - 🔗 Кръг „Споделени фирми“ (2+ длъжностни лица в една и съща компания)
   - ⚠️ Кръг „Роли по Търговския регистър и Пропуски“
   - 📍 Кръг „Област Бургас & Южно Черноморие“
   - 🏙️ Индивидуален избор на всяка община / институция в страната
3. **Пълно досие за всяко лице** — кариерна хронология, свързани компании (ЕИК), вписани роднини, топ институции възложители, най-големи договори и директни линкове към оригиналните XML декларации в `register.cacbg.bg` (Сметна палата).
4. **Национални монополи и поръчки с 1 оферта** — пълен одит от `competition.data` (40.7% / €18.5 млрд. с 1 оферта, индекс HHI, топ 20 двойки възложител–изпълнител).
5. **Отворени файлове за изтегляне:**
   - [`docs/data/SIGMA_2_0_ALL_OFFICIALS_571.csv`](docs/data/SIGMA_2_0_ALL_OFFICIALS_571.csv) — пълен CSV (UTF-8 BOM)
   - [`docs/data/officials_all.json`](docs/data/officials_all.json) — пълен JSON с всички 571 досиета
   - [`docs/data/circles_graph.json`](docs/data/circles_graph.json) — институционални кръгове и споделени фирми
   - [`docs/AUDIT_REPORT_SIGMA_2_0.md`](docs/AUDIT_REPORT_SIGMA_2_0.md) — обобщен одитен доклад

## Възпроизвеждане и обновяване на данните
```bash
python scripts/sync_sigma.py
```
Скриптът декодира директно публичните React Router v7 Turbo Stream отговори от `https://sigma.midt.bg/conflicts.data?role=all`, `/persons/{slug}.data`, `/competition.data`, `/flows.data` и `/network.data`.
